# Troubleshooting

[简体中文](troubleshooting.md) | English

These are diagnostic possibilities, not claims that every target project experienced every issue.

| Symptom                                          | Likely cause                                                     | Check                                                                              | Resolution                                                                                                                                           |
| ------------------------------------------------ | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Blank Pages site; JS/CSS 404                     | Root base on a project subpath                                   | Published HTML URLs, Network, real Pages URL                                       | Rebuild with actual base_path                                                                                                                        |
| HTTP 200 but JS MIME error or unexpected `<`     | HTML fallback, stale preview base, wrong path                    | Content-Type and response bytes                                                    | Align build/preview base, restart preview, fix URLs and rebuild                                                                                      |
| Shader fetch fails or returns HTML               | File absent from output or root-absolute URL                     | Final shader URL, build directory, actual text                                     | Bundle via ?raw or copy assets with base-aware URLs; fetch.text needs no specific shader MIME                                                        |
| Model loads without textures                     | External paths, casing, incomplete copying                       | Model and texture request URLs                                                     | Preserve resource relationships and Linux casing                                                                                                     |
| WASM compilation fails                           | HTML/404 instead of binary or wrong MIME                         | application/wasm and magic bytes 00 61 73 6d                                       | Fix output/URL; use ArrayBuffer instantiation only when streaming MIME requirements fail, retaining errors                                           |
| Worker/WASM glue works locally only              | Internal absolute paths, CORS, dynamic URLs                      | Trace glue/worker requests                                                         | Configure locateFile, worker URLs, and copying; do not depend on dev proxies                                                                         |
| navigator.gpu missing                            | Insecure context or unsupported browser/system                   | HTTPS/localhost and capability detection                                           | Show a clear message; do not disable browser security                                                                                                |
| Null adapter or device rejection                 | Hardware/driver/blocklist or excessive requested features/limits | Separate API, adapter, and device failures                                         | Request only necessary features; explain acceleration/driver checks                                                                                  |
| Shader/pipeline failure                          | WGSL, layout, usage, size                                        | Compilation info, async pipeline rejection, error scope, Console                   | Fix the first error; retain validation                                                                                                               |
| Black image after resize/refresh                 | Depth/canvas mismatch or device loss                             | Backing dimensions, GPU errors, lost promise                                       | Recreate depth within device limits; stop failed loops and provide recovery                                                                          |
| Wrong visibility counts or out-of-bounds writes  | Missing reset, reset within multiple workgroups, bad layouts     | Read actual arguments/indices against reference, including 0/N and repeated frames | Reset before dispatch, separate passes, correct usage flags and alignment                                                                            |
| GPU profiling unavailable                        | Optional timestamp-query unsupported or not requested            | Adapter and device features                                                        | Disable profiling while continuing rendering; never label FPS/CPU time as GPU time                                                                   |
| GPU time reads zero or seems coarse              | Browser timestamp quantization or tiny workload                  | Measurement scope, several samples, documented precision                           | Explain precision; use bigint differences and ns-to-ms conversion; do not invent a nonzero value                                                     |
| configure-pages 404                              | Source not Actions, permissions, repository access               | Pages API and failed step                                                          | Enable Pages and inspect permissions/plan; no PAT embedded in workflow                                                                               |
| deploy-pages/OIDC permission error               | Missing pages/id-token write or environment/branch restrictions  | Job permissions and protection rules                                               | Grant minimum required job permissions; authorized administrators handle protection                                                                  |
| Deployment waits for artifact or serves old code | Wrong artifact, missing needs, wrong run                         | Commit SHA, run, upload/deploy jobs                                                | Correct index.html root, job dependency, and exact-commit tracking                                                                                   |
| CI build fails                                   | Node/casing/devDependencies/lockfile                             | Engines, lockfile, Linux log, clean install                                        | Align tool versions and fix source; do not use continue-on-error                                                                                     |
| npm ci missing optional platform package         | Incomplete lock generated with existing node_modules, npm bug    | Regenerate in an isolated clean directory and rerun ci                             | Preserve user work; move generated dependencies and review the regenerated lock, rather than replacing CI with npm install                           |
| Install stuck resolving optional peers           | npm/tool optional-peer resolution or network                     | npm log, registry, Node/npm versions                                               | Diagnose first; if legacy-peer-deps is necessary, review mandatory peers and persist it in project .npmrc for consistent ci; not a universal default |
| SharedArrayBuffer/WASM threads fail              | Missing cross-origin isolation                                   | crossOriginIsolated and response headers                                           | Existing single-thread fallback or another host; Pages cannot freely set COOP/COEP. Service-worker isolation needs separate evaluation               |
| HTTP succeeds but browser tools time out         | Tool/AX/DOM/page process issue                                   | Supported alternate DOM/AX/screenshot/browser observation                          | Bound retries; preserve HTTP/local evidence and mark online GPU/Console unverified if observation remains impossible                                 |

Prefer production-subpath checks over dev-root checks, inspect bodies rather than status alone, and verify lockfiles/casing across Windows and Linux. Add profiling, WASM, or service workers only when the target project actually needs them.

References: [npm ci](https://docs.npmjs.com/cli/v11/commands/npm-ci/), [npm optional dependencies issue #4828](https://github.com/npm/cli/issues/4828), [WebGPU specification](https://www.w3.org/TR/webgpu/), [cross-origin isolation](https://web.dev/articles/cross-origin-isolation-guide).
